# HaSaN — Personal Portfolio

নিজের পরিচয়, শেখার যাত্রা, skills, project ও যোগাযোগের লিংক দেখানোর জন্য তৈরি একটি responsive personal portfolio website।

## Features

- Responsive layout: mobile, tablet ও desktop-এ ব্যবহারযোগ্য
- Dark cinematic design, orange accent এবং bold heading
- Mobile navigation, active section indicator ও scroll reveal
- Profile photo ও social media icons
- Vanilla HTML, CSS এবং JavaScript; কোনো framework বা build step দরকার নেই

## Run locally

`index.html` সরাসরি browser-এ খোলা যায়। অথবা project folder-এ local server চালান:

```bash
python -m http.server 8000
```

তারপর browser-এ `http://localhost:8000` খুলুন।

## Update your portfolio

- Page-এর লেখা, section এবং profile image path: `index.html`
- Colors, typography, layout ও responsive styles: `css/style.css`
- Mobile menu, active navigation, reveal animation ও footer year: `js/main.js`
- Profile photo এবং social icons: `assets/`

নতুন project যোগ করার সময় প্রকৃত project details, technologies, status ও repository/demo link ব্যবহার করুন। কোনো skill বা achievement-এর অবস্থা বদলালে সেটি বাস্তব অগ্রগতি অনুযায়ী update করুন।

## Deploy with GitHub Pages

1. Project repository-তে পরিবর্তনগুলো push করুন।
2. GitHub repository-র **Settings → Pages** খুলুন।
3. **Deploy from a branch** নির্বাচন করে `main` branch ও `/ (root)` folder বেছে নিন।
4. Save করার পর GitHub Pages প্রকাশিত site-এর link দেখাবে।
